    MIDI Hub help
    
    
  
    
  
    
    
    Routes MIDI between your instruments and a keyboard controller, from one page. Every instrument connects to this computer over USB, and the page passes messages between them as they arrive. It needs a current Chrome or Edge, and routing stops when the page is closed. It's unofficial and not affiliated with Novation, Roland, Waldorf or Akai.
    
    
    Visits to this page are counted anonymously with GoatCounter, which uses no cookies. It never receives your MIDI or setups.
    

    
    Set up
    
    
      
      
    1. Connect each instrument and the keyboard controller to the computer with USB, and turn them on.
      2. 
      
    2. Allow MIDI access when asked. If it says MIDI blocked, click the icon to the left of the address, set MIDI devices to Allow, then click Allow MIDI.
      3. 
      
    3. Check the Devices list. Each one is recognised by its name. If your keyboard shows as Other, set it to Keyboard.
      4. 
      
    4. Set each instrument's channel to the one it listens on. The S-1 starts on 3 and the others on 1.
      5. 
    
    

    
    Quick routes
    
    
      
      
    • Keyboard plays: click an instrument and the keyboard plays it, with its knobs, pitch bend and mod wheel. Click several to layer them. Octave moves what it plays up or down.
      • 
      
    • S-1 sequencer plays: the S-1's sequenced notes play the instruments you click. The S-1 has to send its notes over USB, so check its MIDI settings if nothing arrives. Turn the S-1's volume down if you only want to hear the others. Watch the monitor to see what it sends.
      • 
      
    • Clock comes from: one instrument's tempo, start and stop go to the ones you click, so their sequencers and arpeggiators follow it. Each one also has to be set to follow external clock.
      • 
    
    

    
    All routes
    
    
      
      
    • Every route, including quick ones, is listed here and can be changed. A route takes one input, on every channel or just one, and passes notes, knobs, program changes or clock to one output, on its own channel if you choose.
      • 
      
    • Turning a route off, or changing it, ends any notes it was holding, so nothing gets stuck. Panic silences everything.
      • 
      
    • An instrument can't be routed to itself, as that would loop. Loops through two instruments are still possible, for example if both send back what they receive, so watch the monitor if notes repeat.
      • 
      
    • Save setup keeps the routes under a name, and choosing it from Setup brings them back. Back up and Restore keep everything in a file.
      • 
    
    

    
    With the grids
    
    
      
      
    • S-1 Grid, MPC Grid and Protein Grid send straight to their instruments, so they work alongside this page, open in other tabs. Routes here only carry what the instruments and keyboard themselves send.
